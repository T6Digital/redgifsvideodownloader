RedGIFs Tile Source Copier v7

This version has NO toolbar popup and NO fast-copy mode.

RIGHT-CLICK MENU
Right-click anywhere inside a RedGIFs tile, then choose:

Copy RedGIFs tile source
  - Copy 1 tile
  - Copy 4 tiles in a row
  - Copy 8 tiles in a row

The multi-tile options start with the tile you right-clicked and copy the
next tiles in the current RedGIFs DOM/feed order.

INSTALL
1. Extract the ZIP.
2. Open chrome://extensions
3. Enable Developer mode.
4. Remove/disable the previous version if needed.
5. Click Load unpacked and select this extracted folder.
6. Refresh any RedGIFs tabs already open.
